# 🌍 LinguaLeap – Interactive Language Learning App

**Learn new words. Practice every day. Improve your language skills!**

LinguaLeap is an interactive language-learning web application designed to help users improve their vocabulary through flashcards, pronunciation, quizzes, and progress tracking.

The application provides a simple, engaging, and responsive learning experience with a shiny blue and beige user interface.

## ✨ Features

- 📚 **Vocabulary Learning:** Explore vocabulary across different categories.
- 🃏 **Interactive Flashcards:** Click on flashcards to reveal translations and meanings.
- 🔊 **Pronunciation Support:** Listen to words using browser speech synthesis.
- 📝 **Quick Practice Quiz:** Test your vocabulary knowledge with interactive questions.
- 📊 **Progress Tracking:** Monitor your learning progress and quiz performance.
- 💾 **Local Storage:** Save learned words in the browser so progress persists between sessions.
- 📱 **Responsive Design:** Use the application on desktop, tablet, and mobile screens.
- 🎨 **Modern Interface:** Enjoy a clean blue-and-beige design.

## 📂 Learning Categories

LinguaLeap currently includes these vocabulary categories:

1. Greetings
2. Travel
3. Technology
4. Food & Dining

Each category contains English vocabulary, Telugu translations, pronunciation guidance, meanings, and example sentences.

## 💻 Getting Started

Follow these instructions to run LinguaLeap on your computer.

### Prerequisites

Install the following software:

- [Node.js](https://nodejs.org/)
- [Visual Studio Code](https://code.visualstudio.com/)

### Installation

**1. Clone the repository**

Replace `YOUR_USERNAME` with your GitHub username.

```bash
git clone https://github.com/YOUR_USERNAME/lingualeap.git
```

**2. Open the project folder**

```bash
cd lingualeap
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the application**

Open the local URL displayed in your terminal, usually:

```text
http://localhost:5173/
```

## 🎯 How to Use LinguaLeap

1. Open the application in your browser.
2. Navigate to the Vocabulary section.
3. Choose a vocabulary category.
4. Click a flashcard to reveal its translation and meaning.
5. Use the pronunciation feature to listen to a word.
6. Open Quick Practice to test your knowledge.
7. Visit My Progress to review your learning progress.

## 💾 Data Storage

LinguaLeap uses browser Local Storage to retain learned-word progress between sessions.

This means progress is saved locally in the browser rather than in a remote database.

Clearing browser storage or using another browser may remove or separate the saved progress.

## 📱 Progressive Web App (PWA)

LinguaLeap is being prepared for Progressive Web App support.

Once PWA configuration is completed and tested, the application can support installation and offline access where the browser and configured service worker permit it.

**Note:** Offline functionality depends on the final PWA configuration and caching setup.
